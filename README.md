# ⚡ TINO Reality Debugger

An ultra-futuristic web application designed to act as an **AI Operating System** that enables real-time visual "editing" of reality through AI-powered object detection, 3D hand tracking gesture recognition, procedural audio synthesis, and cinematic augmented reality HUD overlays.

---

## ✨ Features

- 🎥 **Live Camera Feed Background**: High-FPS video stream with sci-fi grid overlays and permission handling.
- 🤖 **AI Vision Scanner**: TensorFlow.js COCO-SSD object detection + neural scanner fallback rendering futuristic bounding boxes, target labels, confidence score ratings, and scanlines.
- 🖐️ **3D Hand Tracking & Gesture Recognition**: Powered by **MediaPipe Hands** landmark detection.
- 💻 **Reality Debug Panel & Source Code Visualizer**:
  - Floating black glass UI with live parameter state controls.
  - Interactive live source code editor displaying `class Object { ... }` with animated line mutation highlights when gestures trigger reality changes.
- 🔮 **Gestures & Reality Powers**:
  - ✊ **Fist**: `Gravity = OFF` (Target object floats up in zero-g with floating particle physics).
  - 👌 **OK Sign**: `Color = Holographic Purple` (Applies glowing purple mesh shader).
  - ✌️ **Two Fingers (V-Sign)**: `Scale = 300%` (Smoothly enlarges object target matrix).
  - 🖐️ **Open Palm**: `Time = Freeze` (Freezes particles & renders chromatic frost state).
  - 👈 **Pointing Finger**: Locks target object nearest to index finger pointer.
  - 🤏 **Pinch**: Resets target object back to default parameters.
  - 🫰 **Snap**: Thanos-style particle disintegration dissolve explosion.
- 🔊 **Procedural Web Audio Sound Engine**: Zero-asset audio synthesizer for scan sweeps, lock chirps, gesture chimes, reality edits, time freeze drops, and dissolve noise.
- 📊 **Cinematic HUD**: Real-time FPS telemetry, CPU load % monitor, AI status, and tracking quality indicators.

---

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Cyberpunk Glassmorphism
- **AI & Vision**: `@tensorflow/tfjs` + `@tensorflow-models/coco-ssd` + `@mediapipe/hands`
- **Audio**: Native Web Audio API Synthesizer
- **Icons**: Lucide React

## 🛠️ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/ritammaity05/tino-reality-debugger.git
cd tino-reality-debugger

# 2. Install dependencies
npm install

# 3. Launch local development server
npm run dev

# 4. Build for production
npm run build
```
